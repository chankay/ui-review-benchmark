# UI 设计验收助手 — 设计规范

> 测评时与截图一起作为输入提供给模型。规范中故意不写移动端安全区与触控热区条款——用来检验模型的移动端经验知识（见 page3 埋点说明）。

## 1. 色彩

| 用途 | 色值 | 说明 |
|------|------|------|
| 品牌主色 | `#534AB7` | 主按钮、选中态、链接 |
| 主文字 | `#1D1D1F` | 标题、正文 |
| 次要文字 | `#6E6E73` | 说明文字、辅助信息 |
| 弱提示文字 | `#86868B` | 最浅可读层级，不得更浅 |
| 成功 / 涨 | `#30D158`（深色）/ `#30B15C`（浅色） | 本素材语义规则：涨=绿（注：A股实际惯例为红涨绿跌，此处为测试语义一致性而虚构） |
| 失败 / 跌 | `#FF453A`（深色）/ `#C0392B`（浅色） | 本素材语义规则：跌=红 |
| 警告 | `#FF9F0A` | 接近配额等中间态 |
| 深色主题背景 | `#1C1C1E` | 页面底 |
| 深色分隔线 | `#2C2C2E` | 不允许更亮 |

## 2. 字体

| 层级 | 字号 / 字重 |
|------|------------|
| 页面标题 | 16-18px / 600 |
| 卡片标题 | 15px / 600 |
| 正文 | 14px / 400 |
| 辅助文字 | 12-13px / 400 |
| 表头 | 12px / 500 |
| 价格数字 | 15px / 600 |

## 3. 间距

| 项目 | 规格 |
|------|------|
| 卡片内边距 | 24px（桌面）/ 16px（移动） |
| 列表行内边距 | 12px 上下 |
| 卡片间距 | 12px（移动）/ 24px（桌面） |

## 4. 形状

| 项目 | 规格 |
|------|------|
| 卡片圆角 | 12px |
| 按钮圆角 | 8px |
| 胶囊标签 | 999px |
| 输入框圆角 | 8px |

## 5. 组件规则

- 状态标签必须使用胶囊底色样式（如 橙底「接近配额」），不得退化为裸文字
- 列表行之间必须有 1px 分隔线
- 数值列（金额、用量）必须右对齐且使用等宽数字（tabular-nums）
- 涨跌必须使用语义色（本素材规则：涨=绿、跌=红），方向符号（+/-）与颜色不得矛盾
- 输入框 focus 态使用品牌主色描边 + 15% 透明度外发光
- 筛选类按钮必须有 1px 描边

## 6. 优先级定义（验收报告用）

| 级别 | 定义 | 示例 |
|------|------|------|
| **P0** | 阻断发布：误导用户 / 数据不可读 / 功能不可用 | 品牌色错误、涨跌色反转、数值列未对齐、安全区缺失 |
| **P1** | 高优：明显视觉不一致，影响品质感 | 字重错误、间距压缩、元素缺失、圆角丢失 |
| **P2** | 低优：轻微偏差，可随下次迭代修复 | 对比度轻微不足、描边丢失、次要色偏差 |
